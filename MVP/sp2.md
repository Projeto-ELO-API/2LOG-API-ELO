# 📌 MVP - Projeto ELO

## 🎯 Objetivo do MVP
- Desenvolver um dashboard funcional no Power BI possibilitando a visualização da taxa de mortes por 100 mil habitantes em sinistros
- Realizar a Análise comparativa para entender a situação de mortalidade entre os estados brasileiros  
- Desenvolvimento de dashboard com indicadores de segurança viária em nível nacional e estadual, para comparar a situação dos estados brasileiros e do país.
- Analisar e entender a real situação de estradas com alto índice de registros de sinistros com base nos dados obtidos

---

## 📝 Descrição da Solução
> Breve explicação do que será desenvolvido e entregue nesta etapa.  
- Funcionalidades principais incluídas  
- Limitações conhecidas  
- Escopo reduzido (somente o essencial para validar a ideia)  

---

## 👥 Personas / Usuários-Alvo
- Analistas de segurança viária que buscam entender causas/fatores associados a sinistros com veículos pesados no trânsito  
- Analistas de saúde pública que buscam entender as principais causas de óbitos no país
- Analista de dados  interessados em visualização de dados logísticosdas

## 📊 Critérios de Aceitação
- Dashboard funcional com dados carregados corretamente 
- Visualizações claras (gráficos e tabelas)  
- Presença de filtros (ex: município, ano, tipo - acidente)
- Análise dos dados com base em pesquisas realizadas
- Pesquisa para entender a real situação de estradas da região
- Inclusão e modificação de filtros no gráfico
- Elaboração de novos filtros no gráfico
